# Whole Foods Location Analysis

**🔗 Live Website:**  
https://victorianian610.github.io/Location_whole_foods/

This repository contains the interactive visualizations, geographic mapping, and final analysis for a Whole Foods location study. Users can explore the full project through the link above.

---

## Project Overview
This project analyzes Whole Foods store locations and sales trends using:

- Python  
- Plotly interactive visualizations  
- Geographic mapping  
- HTML report generation  

The goal is to understand store distribution patterns and potential market opportunities.
